# /script-find

Usage: `/script-find <event> <theme/vibe> [chars] [genders] [min source length] [free only]`

1. Read `../script-cut/references/interp-guide.md`. Read `SHARED_CONTEXT.md` if present (it lists scripts already tried and dropped, don't repeat them).
2. Search. Good sources: author websites with free PDFs, Concord Theatricals previews, Dramatic Publishing excerpts, Brooklyn Publishers samples, JD Drama, Mushroom Cloud Press, Script Slug / IMSDb for screenplays, Wikisource for public domain.
3. **Before recommending, verify** (open the PDF/page):
   - Format: true monologue vs. multi-character (DI user wants mostly monologue).
   - Character count and genders.
   - Length of the original (word count or listed minutes).
   - Free complete PDF vs. preview vs. paid. Never call a preview "the full script."
   - Theme actually matches (don't stretch).
4. Reply: 1 main pick + up to 2 backups. For each: title, author, link, 1-line story, why it fits, format/chars/length, free or paid, content warnings. Then one line on what it would take to cut.
5. If nothing meets every requirement, say which one it misses. Don't pretend.
