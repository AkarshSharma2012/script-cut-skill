# Contributing

Thanks for helping. Most people who use this are students, so keep things simple and friendly.

## Good first contributions
- Add rules for another league (NCFCA, Stoa, state leagues, college AFA/NFA) to `skills/script-cut/references/interp-guide.md`.
- Add a new public-domain demo under `examples/` (Shakespeare, Chekhov, Wilde, Poe).
- Improve a command's SKILL.md so the output is clearer.

Look for issues labeled **good first issue**.

## Rules
- Never add copyrighted script text. Only public-domain sources in `examples/`.
- Skills must never tell the agent to contact anyone or edit the user's original files.
- Spoken lines in cuts stay the author's exact words. Don't add rewriting features.
- Run `npm test` and `npm run check` before opening a PR.
